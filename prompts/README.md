## 
Для работы с YandexGPT Pro (в том числе через Playground или API-консоль) используется единая среда — Yandex Cloud. В отличие от OpenAI, здесь нет отдельного публичного сайта «Playground» для мгновенных тестов без регистрации. 
##
Вот как зайти и настроить доступ:
1. Вход в консоль
Перейдите на сайт: https://console.yandex.cloud/.
Нажмите «Подключиться» или «Войти», используя ваш Яндекс ID (аккаунт Яндекса/Почты).

##
2. Подготовка аккаунта (обязательный этап)
Сервис платный, поэтому перед тестированием нужно выполнить настройки:
- Создайте платежный аккаунт: в консоли перейдите в раздел Billing, привяжите банковскую карту и пополните баланс (минимальная сумма обычно составляет 500 рублей) https://habr.com/ru/articles/780008/
- Создайте каталог (Folder): если он не создался автоматически при регистрации облака. Идентификатор каталога (folder_id) отображается в строке навигации сверху — его нужно скопировать.
- Создайте сервисный аккаунт: выберите нужный каталог → вкладка «Сервисные аккаунты» → «Создать сервисный аккаунт». Назовите его (например, yandexgpt-user).
- Назначьте роль: нажмите «Добавить роль» и выберите ai.languageModels.user (или playground.user, если интерфейс предлагает такой вариант). Это разрешение необходимо для запуска моделей.
- Сгенерируйте API-ключ: внутри созданного сервисного аккаунта нажмите «Создать новый ключ» → «Создать API-ключ». Скопируйте значение ключа сразу — после закрытия окна оно больше не будет показано.

##
3. Как прогнать промпт вручную

Вариант А: Через Python-код (самый простой способ теста)
Создайте файл .py и используйте библиотеку requests. Вам понадобятся скопированные ранее API-ключ и ID каталога:

python

import requests
prompt = {
    "modelUri": "gpt://<ВАШ_ИДЕНТИФИКАТОР_КАТАЛОГА>/yandexgpt-pro",
    "completionOptions": {"temperature": 0.6, "maxTokens": 2000},
    "messages": [
        {"role": "system", "text": "[ТЕКСТ ВАШЕГО ПРОМПТА ИЗ README.md]"},
        {"role": "user", "text": "Ваш вопрос"}
    ]
}

url = "https://llm.api.cloud.yandex.net/foundationModels/v1/completion"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Api-Key <ВАШ_API_КЛЮЧ>"
}

response = requests.post(url, headers=headers, json=prompt)
print(response.json())

Вариант Б: Через cURL (прямая отправка из терминала)
Откройте терминал и выполните команду:

bash

curl https://llm.api.cloud.yandex.net/foundationModels/v1/completion \
  -H "Authorization: Api-Key ВАШ_API_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "modelUri": "gpt://ВАШ_ID_КАТАЛОГА/yandexgpt-pro",
    "messages": [
      {"role": "system", "content": "Текст промпта из вашего файла"},
      {"role": "user", "content": "Тестовый запрос"}
    ]
  }'

  ## 
  Обратите внимание: использование YandexGPT требует наличия активного платежного профиля. Если вы планируете только разовое тестирование, убедитесь, что на балансе достаточно средств для оплаты минимального объема токенов.

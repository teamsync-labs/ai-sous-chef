# Сравнение версий: v2 → v3

| Критерий | v2 (Старая версия) | v3 (Новая версия) |
| :--- | :--- | :--- |
| **Объём ответа (токены)** | 500 – 800 | - |

🏁 Итог

В v3 исключен лимит ответа в токенах, v2 модель могла «пытаться» уложиться в 800 токенов, тратя дополнительные токены на подсчёт — вместо полезной работы.

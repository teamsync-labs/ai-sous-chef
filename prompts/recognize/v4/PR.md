# Улучшения промпта: v3 → v4

## Что изменилось

## Сводная таблица

| Аспект | v3 | v4 | Влияние |
|--------|----|----|---------|
| Определения продукта | Примеры в скобках | Два раздела с категориями (бакалея, молочное, мясо, овощи, хлеб, напитки, упаковка) | Меньше ложных отказов и ложных включений |
| Обработка готовых блюд | Одна строка «исключай готовую еду» | Отдельный раздел с алгоритмом разбора блюда на ингредиенты | Убирает главный триггер зацикливания |
| Правила для quantity/unit | 1 правило (только null) | 4 правила (число+единица, число без единицы, единица без числа, ничего) | Покрывает все пограничные случаи |
| Шкала confidence | Просто диапазон 0.0–1.0 | Диапазон + интерпретация по уровням | Осмысленные значения вместо случайных |
| Якорь формата | «Верни ТОЛЬКО валидный JSON» | «Первым символом ОБЯЗАН быть `{`» | Резко снижает риск ухода в рассуждения |
| Примеры | 1 пример | 3 примера (обычный, блюдо, отказ) | Модель видит все сценарии |
| Критерии отказа | 7 пунктов без нумерации, без «иначе» | 6 нумерованных + строка «во всех остальных случаях верни JSON» | Быстрее, без зацикливания, без ложных отказов |
| Алгоритм | Отсутствует | Финальный блок из 4 шагов | Линейная логика вместо хаотичного набора правил |
| Блок «Правила бюджета размышлений» | Есть, 7 пунктов | Удалён полностью | Убирает невыполнимые инструкции, создающие шум |
| Порядок блоков | Роль → правила → формат → пример → отказ → бюджет | Роль → что продукт → что не продукт → блюда → правила → формат → примеры → отказ → алгоритм | Читается в порядке применения |

## Ключевые различия по секциям

| Секция | Что изменилось | Зачем |
|--------|----------------|-------|
| 🥦 Продукт / не продукт | Разбито на два явных списка с категориями | Чёткие границы классификации |
| 🍲 Готовые блюда | Вынесено в отдельный блок с алгоритмом разбора | Устраняет зацикливание на сложных случаях |
| 🔢 quantity / unit | Расширено с 1 до 4 правил | Полное покрытие пограничных случаев |
| 📈 confidence | Добавлена уровневая интерпретация | Предсказуемые значения на выходе |
| 🔒 Формат вывода | Усилен якорь `{` как первый символ | Гарантирует чистый JSON без рассуждений |
| 📚 Примеры | 1 → 3 сценария | Few-shot обучение на всех кейсах |
| 🚫 Отказ | Нумерация + fallback-строка | Исключает «зависание» модели |
| 🧭 Алгоритм | Новый финальный блок из 4 шагов | Линейный порядок принятия решения |
| 🗑️ Бюджет размышлений | Удалён | Убирает шум и невыполнимые инструкции |
| 📐 Порядок блоков | Перестроен под логику применения | Промпт читается сверху вниз как инструкция |

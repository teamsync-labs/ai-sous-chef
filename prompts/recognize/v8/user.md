# ШКАЛА CONFIDENCE
- 1.0 — все продукты и количества однозначны.
- 0.8 — есть готовое блюдо/полуфабрикат с различимыми базовыми продуктами,
  либо небольшая неоднозначность в названии.
- 0.5 — часть продуктов под вопросом, использованы обобщённые названия.
- 0.0 — пустой список (продукты не распознаны).

Сейчас: /start

/start

Ознакомительное сообщение. Две точки входа — фото и текст.

  • Без авторизации
  • Один запрос — один ответ
  • Дальше — подтверждение продуктов

Карта экранов (mobile)

  • Splash — логотип + название
  • Home — фото / текст
  • Camera — React Native
  • Recognizing — лоадер ≤5 с
  • Confirm — products + Верно / Неверно
  • Retry — «отправьте фото ещё раз»
  • Text — поле + «Найти рецепты»
  • Recipes — список title
  • Detail — steps[]
  • Error — 422 / 502

Сознательно вне UI

  • Чат и диалог с ИИ
  • Правка списка продуктов вручную после фото
  • Авторизация / профиль
  • История запросов
  • Список покупок, калории, диеты
  • Соцфункции и умная техника

Визуальное направление

  • Кухонный «sage/forest» — зелёный акцент, светлая поверхность
  • Шрифты: Instrument Serif (бренд) + Sora (UI)
  • Минимум карточек: только интерактивные блоки (режимы, рецепты)
  • Один job на экран — без дашборда и вторичных виджетов

Telegram (параллельный клиент)

  • /start → intro
  • фото/текст → «Продукты распознаны» + inline Верно / Неверно
  • Верно → список рецептов в сообщениях → шаги
  • Неверно → «попробуйте ещё раз»
  • Тот же backend, без отдельного API для бота
